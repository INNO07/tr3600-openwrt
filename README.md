# Cudy TR3600 V1 主路由定制候选

完整源码、补丁、配置和测试位于 `TR3600-build-kit.zip`。这不是可刷固件。
工作流先核对源码包 SHA256，再解包并验证各文件，然后执行测试和编译。

进入 Actions → TR3600 candidate build → Run workflow。
编译成功后下载同名 Artifact，包含镜像、完整配置、包清单、校验值及日志。

基础版本固定 OpenWrt 25.12.5；包含中文 LuCI、OpenClash、cloudflared、SSH 和网页终端。
Mihomo ARM64 内核作为同批附件提供；奇游只预留依赖，安装与共存需实机验证。
包含 TR3600 V1 无线、双 2.5G 网口、风扇与 LED 支持，以及 Cudy 双槽启动补丁和升级保护。

当前仅完成源码适用性、语法及 7 组模拟测试；尚未完成云端编译或设备验收。
绿色 Actions 不代表稳定性验证。刷写前保持原厂，核查最终产物后再按 Cudy 官方中间固件流程操作。
无线地区默认 CN、可选，功率可手动调节，但实际范围仍受地区、驱动和校准数据限制。

修改源码包时，需要同步更新工作流中的包 SHA256。详细技术说明和验收步骤在源码包 README.md 中。
